# 💈 App Salon MVC PHP

A salon management web application built with **PHP using the MVC (Model-View-Controller) architecture**.

The application allows users to create accounts, log in, book appointments, and select salon services. It also includes an administrator area for managing users, appointments, and services.

## ⭐ Live Demo

[Live Application](https://appsalon-phpmvc-michaelacostadev.mnz.dom.my.id/)

[GitHub Repository](https://github.com/MichaelAcostaDev/app-salon-mvc-php)

## ✅ Features

* User registration and authentication
* Administrator authentication and management
* Appointment scheduling
* Salon service management
* User and appointment management
* Session handling
* Password hashing
* Email functionality
* MySQL/MariaDB database integration
* Responsive frontend
